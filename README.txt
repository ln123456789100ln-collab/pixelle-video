========================================
  Pixelle-Video - Windows 便携版
========================================

AI 视频生成工具
- 素材拼接模式：上传图片/视频素材，AI 生成配音+字幕
- 混合批量模式：上传≥15个素材，随机抽取批量生成 N 条视频
- 7 套健身模板，随机模板 + 随机 BGM
- 高质量 CRF 18 编码

版本: 0.1.15

========================================
  快速开始
========================================

1. 解压到任意目录（路径建议不要有中文和空格）
2. 双击 start.bat
3. 首次运行会自动安装依赖（等待 2-5 分钟）
4. 浏览器自动打开 http://localhost:8501
5. 在 Web UI 的"设置"中配置 API 密钥
6. 开始生成视频！

========================================
  首次配置
========================================

1. 在 Web UI 中点击"设置"(Settings) 配置：
   - LLM API Key（必填）
   - LLM Base URL 和 Model
   - ComfyUI 配置（使用 RunningHub 或自建 ComfyUI）
2. 点击"保存配置"
3. 返回首页，选择"🎨 自定义素材"或"🎲 混合批量"模式

========================================
  目录结构
========================================

python/           - Python 3.11 运行环境
tools/            - FFmpeg 等工具
Pixelle-Video/    - 主程序代码
data/             - 用户数据（BGM、模板等）
output/           - 生成的视频
temp/             - 临时文件（可清理）

========================================
  系统要求
========================================

- Windows 10/11 64位
- 8GB+ 内存（推荐 16GB）
- 20GB+ 硬盘空间
- 已安装 Chrome 浏览器
- 网络连接（用于调用 AI 接口）

========================================
  常见问题
========================================

问题: "Python not found"
解决: 确保解压完整，python/ 目录存在

问题: "Failed to start"
解决: 检查 Python 和依赖是否正确安装。删除 .venv/ 目录后重新运行

问题: "端口被占用"
解决: Streamlit 会自动使用下一个可用端口

问题: 提示 "Module not found"
解决: 确保解压完整，不要移动文件。可删除 .venv/ 后重新运行
